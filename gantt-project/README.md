# Gantt Project Dashboard — Analisis Data Akademik

Website interaktif yang mengubah rencana Gantt Chart Microsoft Project menjadi dashboard web responsif.

## Fitur
- Gantt Chart berdasarkan 39 item task.
- Summary task, milestone, duration, start, finish, predecessor, resource, progress 0%.
- Pencarian dan filter tahap/resource.
- Ringkasan proyek, dependensi, resource.
- Print-friendly.
- Arsip file Excel dan Microsoft Project XML.
